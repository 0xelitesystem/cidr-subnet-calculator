CIDR Subnet Calculator

IPv4 subnetting in your browser

Enter an IPv4 address with a CIDR prefix, for example 192.168.1.0/24. You get the network and broadcast addresses, netmask, wildcard mask, usable host range, host counts, and a binary view. There is also a helper to split the block into equal subnets. Nothing leaves this page.

Accepts a /prefix from 0 to 32. If you enter a host address such as 192.168.1.42/24, it is normalized to the containing network.
